How the ledger works

The ledger is one list of rows. Each row has a supplier, a client (party), an invoice number, a date, a net amount and a sales month. Dashboard, Supplier, Party, All parties and Report are only different ways of adding up the same rows for the month chosen at the top.

Checking and uploading

  1. Upload: choose the supplier, report type, sales month, then the PDFs. For an account ledger statement, only the SALES rows are taken; payments, opening balance and totals are skipped.
  2. Read the bar above the table: rows read, total net amount, and how many need attention.
  3. Check each net amount against the PDF. Use “Pick” to choose another number found in the file, or type it.
  4. Fix the invoice number, date, client or sales month if needed, then press Save.

Deleting mistakes

Wrong upload: Upload → Recent uploads → Delete upload (tap twice). One row: Ledger → ✕.

Client names

Names are never changed automatically. Correct a name in the check table or in the Ledger, or use Names → Rename to fix a spelling everywhere. Renaming to a name that already exists merges them.
